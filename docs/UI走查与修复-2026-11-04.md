# UI 走查与修复（2026-11-04）

本轮以 a7a4c72 为基线，使用隔离的本地演示库及浏览器检查。未在生产账户发消息、下单或变更权限；发布通过 Git 更新脚本执行，并另行核验服务器版本与公网资源。

## 已修复问题

| 问题 | 原因与结果 |
|---|---|
| 收起聊天仍把消息标为已读 | 组件只被 CSS 隐藏，轮询继续；现在根据真实可见状态暂停列表、消息和成员请求。 |
| 离开聊天或打开好友管理丢草稿 | 条件渲染卸载了 ChatDock；现在保持组件挂载，隐藏时停止请求，保留当前会话、草稿和引用。 |
| 慢网络下消息可能一直加载 | 4 秒轮询不断让未完成请求的全局版本过期；现在每个会话只允许一条在途读取，写入后串行取得新记录。 |
| 群主无法撤回别人或较早的消息 | 按钮能力字段与实际 API 权限不一致；现在群主可撤回所有未撤回消息，普通作者仅限 2 分钟内，已撤回消息不再给按钮。 |
| 手机引用昵称被挤成竖排 | 引用行作者参与压缩；现在作者单行截断，预览文本负责伸缩。 |
| 手机顶栏账户指标横向溢出 | 旧移动样式没有作用于新的 status-row；现在窄屏隐藏重复账户指标，保留品种、价格和连接状态。 |

## 交互优化

- 资料栏提供明确的关闭按钮。
- 表情替换选中文字或插入光标位置，点击外部可关闭选择器。
- 输入框随多行文字增高，最多 150px；新消息按钮跟随输入区位置。
- 桌面嵌入聊天栏限制为窗口约 72%，给 K 线保留空间；手机展开聊天充分利用屏幕。
- 聊天尺寸改变时，仅在原本接近底部的情况下保持跟随新消息。

## 验证

- HTTP 集成检查：371 项通过，全部使用临时生成数据。
- 前端：`CHART_BASE=/chart/ npm run build` 通过，包含 TypeScript 检查与最终构建；部署前默认 CDN 构建也通过。
- 浏览器：真实 390px iframe 视口，检查聊天列表、引用、资料关闭和全屏；另检查 768px / 1100px 宽度。
- 表情与草稿：在 ABCD 的 A 后插入 👍，切换交易再返回，仍为 A👍BCD，当前会话保留。
- 已读：收起聊天后注入一条合成消息，多轮轮询间隔后数据库 read_at 仍为空；打开会话才读到该消息。
- 慢网：仅在验收用开发代理为私信读取固定增加 6 秒延迟，消息仍正常展示；这项延迟不属于产品代码。
