# 图表拖线下单与改单

交易台连接本机 SyncTrade 后，在当前券商轨道、当前品种的实时图表上显示两类价格线。

- “同频待下单”：入场、已启用的止损与止盈对应右侧下单票据。拖动只改票据，不会自动下单；以损定仓模式重新计算手数，旧确认取消。市价入场线拖动后按买卖方向和当前 bid/ask 转为限价或止损挂单，所需动作必须在 EA capabilities 中。已有挂单票据保留原类型，仍按原校验规则提交。
- “同频持仓 #编号”：已开仓持仓的开仓价格锁定；止损、止盈松手后向本机 EA 发送一次 modify，保留最新持仓快照中另一侧的价格。EA 使用 TRADE_ACTION_SLTP 修改真实持仓，并推送新快照；持仓列表与图表随快照更新。

持仓线只有在账户、会话、品种与券商轨道匹配且 EA 授权 modify/持仓管理时可编辑。价格按券商 tick_size 和 digits 对齐。程序刷新、锁线、主题切换和多格镜像的重复事件不会重复提交。回放隐藏交易线并屏蔽其编辑；交易线也不进入画线存档、笔记证据或分享切片。

等待回报期间以最新已知持仓价格为准。被拒、发送失败、超时、uncertain 或 not_found 会提示核查，并恢复最后已知价格，不自动重试。结果不确定不能解释为改单失败；请用“只查询执行结果”或 MT5 确认。切换账户后旧会话的回报轮询停止，不覆盖新账户图表。

本次复用已有 SyncTrade 1.113 的 modify 与 symbol_spec，EA 源码和权限不变。已在券商服务器挂出的 pending order 不在本次拖线改单范围内；现有 EA 对其修改仍不支持，待下单票据与已开仓持仓需区分。

实现：web/chart-src/src/trade/chartOrders.ts、OrderTicket.tsx、vela/orderLevels.ts、vela/ChartWorkspace.tsx、App.tsx、LocalTradePanel.tsx。测试覆盖真实票据重算与确认取消、价格网格、单次改单保留另一侧价格、权限与会话隔离、拒单/未知结果/超时回退、程序绘图事件与多格去重。前端测试和构建不能替代 MT5 的实际交易验收。
