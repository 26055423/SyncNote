# 开发协作

仓库为私有，拥有仓库链接本身不代表可以访问，需要所有者邀请。

所有者在 GitHub 打开 Settings → Collaborators → Add people，输入朋友的 GitHub 用户名，核对账号后发送邀请。朋友接受邀请后才能拉取和提交。不要转发 GitHub 密码、访问令牌或服务器密码。

每次修改使用新分支，提交 Pull Request，再由所有者审核合并。这里是协作约定；没有宣称已开启套餐相关的强制分支保护。`main` 保存可运行版本，功能分支用于试验。

不配置自动发布到现用服务器。每个人在自己的开发环境和数据库测试，通过后由各自部署者升级。Git 提交及 Pull Request 仅保存代码，不同步网站上的账号或交易记录。

建议不要执行 `git add .` 盲目添加整目录；用明确文件名添加，提交前检查 `git diff --cached` 和 `git status`。`.gitignore` 是附加保护，不能替代核对。
