- 最新迁入的 `bridge/WebBridge.mq5` 包含真实交易执行源码，但依赖 Python gateway；已保留原实现。

- 网页的配对令牌仅存内存；默认不上传新本机数据，断线后不转云端下单、不自动重发交易。

## 发布前审阅已处理的问题

配对前账户信息泄露、断线无法重新配对、历史请求并发冲突、旧 journal 查询带旧 epoch、净额持仓无法按 magic 隔离、挂单修改能力不一致、报价精度固定两位、历史未就绪就初始化图表，以及单笔成交不能证明整笔请求完成的回报语义，均作为首版核查项处理。

## 必须保留的未验收项

1. 源码在用户 MT5 版本上编译、挂载，浏览器 HTTPS → 真实 EA 的来源校验、配对与本地确认。
2. 对照实际 tick、券商时间、四周期 K 线和持仓；历史跨夏令时的当前 offset 近似需单独核对。
3. 模拟账户的下单、部分成交、平仓、撤单、SL/TP 修改和券商拒绝回报。
4. 提交前后断线、EA / 浏览器重启、本地 journal 恢复，以及原 command_id 的查询和禁止自动重放。
5. 慢客户端、大历史、多窗格情况下的队列和调度；采集 p50 / p95 / p99 与失败样本。

用户电脑的 EA 安装、DLL 授权和配对是本地操作，服务器发布不会替用户完成。后续离线 UI、自动云端同步、手机/远程连接和实盘支持分别立项，不属于本次预览版。
