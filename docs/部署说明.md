# 独立服务器部署

1. 安装 Docker Engine 和 Compose v2，拉取私有仓库。
2. 复制 `.env.example` 为服务器本地 `.env`，设置自己的管理员用户名、网站域名与Cookie策略。不要提交 `.env`。
3. `docker compose up -d --build` 构建并启动。
4. `docker compose exec tongpin python bootstrap_admin.py`，在终端交互设置新管理员密码；不使用命令行参数或聊天传递密码。
5. 给自己的域名配置DNS与HTTPS反向代理。示例为Caddy，应用端口仅监听回环。HTTPS启用后 `COOKIE_SECURE=1`，`PUBLIC_ORIGIN` 必须与浏览器访问来源一致。
6. 登录后设置管理员二次验证，在个人中心取得一次性邀请码给新成员注册。
7. 测试两位独立成员登录、隐私开关、退出/改密、自己的MT5同步与复盘，再开放使用。

升级：先在自己的服务器备份数据卷，再 `git pull --ff-only`，然后 `docker compose up -d --build`。不要删除卷。服务不自动拉取GitHub更新，避免未经审核代码直接上线。

图表页（`/chart`）的镜像采用两段构建：先在 `node:22-slim` 里执行 `npm ci && npm run build`，再把 `web/chart/` 静态产物复制进最终镜像。运行时的镜像仍然只有 Python，不需要 Node，也不需要联网。仓库里同时带着一份构建好的 `web/chart/`，所以不用 Docker 直接 `python app_server.py` 也能打开图表页；改动 `web/chart-src/` 后要重新构建，否则 `/chart` 还是旧版本。

`/api/chart/*` 与 `/api/reviews/*` 只读写本实例数据库：画线存档保存在 `chart_states`，作业保存在 `review_shares`。图表行情沿用复盘已有的数据来源（MT5 同步或 Dukascopy 参考行情），不新增第三方服务。

## 不用 Docker 时（systemd + nginx）

只需要 Python 3.9+（代码用到 `zoneinfo`，不需要 pip 包）和一个反向代理：

```ini
# /etc/systemd/system/tongpin.service
[Unit]
Description=Tongpin trading journal
After=network.target
[Service]
User=tongpin
WorkingDirectory=/SyncTrade
Environment=HOST=127.0.0.1
Environment=PORT=18886
Environment=DATA_DIR=/SyncTrade/data
Environment=PUBLIC_ORIGIN=https://自己的域名
Environment=COOKIE_SECURE=1
Environment=ADMIN_USERNAME=admin
ExecStart=/usr/bin/python3 /SyncTrade/app_server.py
Restart=always
[Install]
WantedBy=multi-user.target
```

nginx 侧把 80/443 反代到 `127.0.0.1:18886`，并转发真实客户端 IP：

```nginx
location / {
    proxy_pass http://127.0.0.1:18886;
    proxy_set_header Host $host;
    proxy_set_header X-Auth-Client $remote_addr;
}
```

`X-Auth-Client` 只在本机回环地址可信（`TRUSTED_PROXY_CIDRS` 默认 `127.0.0.1/32`），外部直接伪造该头无效。

## 更新代码

服务器上 `/SyncTrade` 是 `26055423/SyncNote` 的 git 检出，部署密钥是只读 Deploy key。更新一条命令：

```sh
sudo tongpin-pull
```

它会 `git pull --ff-only`，有变化才重启服务，健康检查失败自动回滚到上一版。

没有部署密钥时，也可以从本地打包上传：

```powershell
pwsh -File tools\deploy.ps1 -Server <服务器IP> -User <ssh用户>
```

服务器端需要先装一次 `tools/tongpin-deploy.sh`：

```sh
sudo install -m 755 -o root -g root tongpin-deploy.sh /usr/local/bin/tongpin-deploy
```

它会停服务、把旧 `data/` 复制进新目录、整体换目录、重启，并在健康检查失败时自动回滚到上一版。

GitHub不会运行这个Python服务；这里没有配置GitHub Pages。朋友的服务器地址、域名和运行环境需要在实际部署时提供，本仓库不附带任何现用服务器配置。

当前机器完成的是Python服务与接口检查，不代表已经验证Docker构建或在另一台服务器部署成功。没有安装/更改当前现用服务器上的容器。
