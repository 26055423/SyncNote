# SyncTrade 1.102 修复验收记录

日期：2026-11-02。基于 `2ba5bfc` 的审阅问题修复。

## 行为变化

- 修正两处字面量换行，去掉前后矛盾的“最终只能模拟账户”判断。默认仍只读，实盘需要明确的本地总开关、实盘开关和有效限额，网页保留实盘二次确认；未知与竞赛类型不开放交易。
- 净额账户未同意管理时，只有同品种既无持仓也无挂单才允许市价开仓；不会把反向减仓当成普通新仓放行。净额挂单、平仓和改单必须明确授权；magic 限制继续生效。落盘后、提交前再次复核。
- EA 同时声明具体 `limit/stop` 能力，并保留 `pending` 兼容旧页面。新网页逐动作授权，缺失某个动作时就禁用对应操作，不用兼容标签扩大权限。
- 挂单触发价按市场与券商最小距离检查，SL/TP 按委托价检查，显式采用 RETURN。挂单放置得到 10008 后结束放置命令，订单仍在挂单列表，可以随后撤销；不把“放置成功”称为成交。市价 10008 和 RETURN 部分成交继续保持待核实。
- 每日亏损按券商日、当前配置品种的全部来源历史统计，涵盖 IN、OUT、INOUT、OUT_BY、佣金、费用和隔夜利息；明确归属该品种的独立费用也计入。存款/信用不抵消交易亏损，无品种费用不猜测分配。读取失败或金额异常拒绝新开仓。
- 每日实盘次数改为账号/券商隔离、独占锁定、SHA 链校验的持久日志，先预约再写执行意图和提交。无效参数不扣次数；未发送或立即明确拒绝释放，已接受/完成/未知保留，重挂重启不清零。券商午夜跨日的在途提交拒绝并释放旧日预约。
- 保留单次发送和持久命令去重；持仓/挂单无法读取、风控日志异常、账号/权限变化或指令过期时都不能继续提交。

## 范围

次数限制是该 MT5 数据目录内本 EA 的新委托次数，并非券商账户级全局限制；其他终端、手动或其他 EA 委托不受它限制。已经接受后再撤销的挂单仍占当日次数。亏损限额不限制已授权的减仓操作，但风控存储损坏会禁止全部交易。

MT5 的历史、行情和 OrderSend API 仍可能内部阻塞。净额持仓最终复核也不是券商原子隔离，需避免同时从多个来源修改同一品种。上述测试用合成 API 验证分支和文件恢复，不代替真实终端挂载、DLL 调用、浏览器配对和券商订单生命周期验收。本次不操作图表挂载、不开启实盘、不发送订单。网页源码与构建产物已更新，本次未部署服务器。
