# 交接范围

本仓库只包含同频独立源码、公开页面资源、通用认证工具、空库初始化代码与部署文档。

没有复制数据库、SQL数据导出、现有账号、密码哈希、交易记录、会话、验证码数据库、用户附件、个人笔记、密钥、正式环境文件或服务器日志。不包含其他模块页面与共享身份服务，不设置其他服务的连接地址。

程序中的表定义用于首次启动创建全新的空数据库，不是导出现有数据库。测试中的账号及数据全部为运行时生成的合成测试数据；示例配置没有默认密码。测试时产生的数据只位于临时目录。

原生可执行文件、预绑定连接包、截图、旧备份及文件系统元数据不在上传范围内。不会把原工程的 Git 历史带入新仓库。

本实例不默认连接任何现用网站。网站域名由部署者设置；MT5采集源码中的 WebsiteURL 默认留空，必须填写自己的地址。公共行情工具包含公开行情提供方地址，不包含其私人API或账号，且默认不后台调度。
