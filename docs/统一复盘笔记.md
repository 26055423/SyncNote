# 统一复盘笔记

更新：2026-11-10，数据库版本 6。

## 使用方式

复盘只有一种笔记。历史订单的「复盘」打开关联笔记；浏览图表、选择日期或回放时，点击顶栏「开始复盘」创建独立笔记。相同图表时刻可以有多篇笔记，订单可以关联或取消关联。右栏「我的笔记」支持搜索与分页，再次打开时恢复图表场景。

可以直接写自由笔记，也可以选择方向判断、结构、关键位、入场模型、订单管理、结果与改进等章节，自定义标题、顺序和个人模板。章节与清单都不自动套用。只有显式添加的检查项显示勾选与结论；分组本身不代表检查项。旧分组、勾选与结论保留，未声明类型的旧条目按原数据兼容判断。

章节用稳定列表选择；正文旁的常用语点击后插入光标位置，可连续插入。插入目标可以是章节正文、自由笔记或当前图表的指定画线批注。点击「写入图表批注」后选择目标图形。选中文字可以保存为个人常用语，常用语和模板可固定；使用一次不会自动收藏。传统词云保留在「更多常用语 / 找灵感」内，只负责插入正文。

编辑文字后约 1.2 秒自动保存，也可手动保存；失败保留本地内容并显示错误，改动内容或手动保存后重试。画线变化另行延迟保存。尚未保存的文字在切换笔记前提示。

## 数据与兼容

- `review_notes.id` 是笔记身份；`person` 是所有者，`ticket` 是可空的订单关联。
- 正文、标签、章节、画线文档和 `scene` 保存在笔记内。场景记录行情轨道、品种、UTC 毫秒锚点、周期、布局、可见范围，以及回放光标和已知行情截止时刻。
- `primary_ticket` 只负责旧订单深链与旧 API 的兼容映射。版本 6 迁移旧正文、章节和画线；不删除或重写旧记录。
- 旧 `/api/journal`、`/api/chart/state` 写入会同步对应笔记；编辑原有订单笔记也会更新旧表，旧客户端遗漏章节时继续保留章节。额外创建的笔记不伪造成交易，不进入交易重建通道。
- 个人模板、标题收藏与常用语保持原表和原 ID。统计从独立笔记读取，普通章节不计入清单完成度。
- 旧的按订单查看好友复盘入口保留；新的独立笔记仅所有者可读写，其他人经明确分享的快照访问。

## API

| 接口 | 用途 |
|---|---|
| `GET /api/notes?q=…&offset=…` | 个人笔记列表，50 条一页 |
| `POST /api/notes` | 无 id 时新建；有 id 时更新所有者的笔记，遗漏字段保留 |
| `GET /api/chart/entry?note=…` | 笔记、场景、画线和可选订单 |
| `GET /api/chart/bars?note=…` | 笔记绑定轨道行情；共用分页及 UTC 换算 |
| `POST /api/reviews/share` | `note_id` 指定独立笔记，分享给可聊天的好友 |
| `POST /api/groups/share` | `note_id` 指定独立笔记，分享给当前群成员 |

分享对话框打开时冻结正文、画线、可见范围和回放进度，即使正文尚未自动保存，也分享对话框打开时的内容。每次发送生成新的不可变快照。回放分享的行情接口以记录的截止时刻过滤未收盘和未来 K 线，收件人看到只读切片；作者重新打开自己的笔记可以继续回放。群内晚加入成员仍打开原快照，退出群或撤回后不能再访问。

公共词库仅返回预置词语，不再从私人笔记标题或正文聚合。分享笔记不会公开个人词库或模板。

## 验证与升级

运行 `python3 tests/run.py` 和前端 `npm run test:local`、`npm run build`。`tests/test_review_notes.py` 覆盖独立身份、可选订单、旧客户端兼容、越权、回放行情截止、草稿冻结、群内晚加入与撤回、词库隐私。浏览器检查补充光标插入、目标切换、图形批注、回放中新建和恢复。

升级前在生产数据库的私有副本上演练版本 5 → 6，校验旧表内容和旧分享链接不变。部署继续使用支持代码与数据库同时回滚的 `syncnote-pull`。
